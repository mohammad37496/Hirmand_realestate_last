# موسیقی سایت هیرمند

برای اضافه کردن موسیقی:

1. فایل MP3 / OGG / WAV را در همین پوشه قرار دهید.
2. فایل `playlist.json` را باز کنید.
3. برای هر آهنگ یک مورد داخل آرایه `tracks` اضافه کنید:

```json
{
  "title": "نام آهنگ",
  "artist": "نام خواننده",
  "src": "/music/song-name.mp3"
}
```

اختیاری:
- `cover` برای تصویر کاور آهنگ، مثلاً `"/images/music-cover.jpg"`.
- برای جلوگیری از تلاش پخش خودکار، مقدار `autoplay` را `false` کنید.

مرورگرها ممکن است پخش خودکارِ همراه صدا را قبل از اولین تعامل کاربر مسدود کنند. پلیر سایت این حالت را تشخیص می‌دهد و با اولین تعامل/فشردن دکمه پخش، موسیقی را ادامه می‌دهد.
